# دليل تشغيل صقر SAQR v6.0 — من الألف إلى الياء

## 1) ما هو المشروع؟

| جزء | المسار | الوظيفة |
|-----|--------|---------|
| **المحرك** | `bin\saqr.exe` | Rust: WS Binance + قرار + API |
| **اللوحة** | `web\control_terminal\` | http://127.0.0.1:8787 |
| **الإعدادات** | `.env` | Binance / Telegram / mode |
| **السجلات** | `logs\` | `saqr-run.log` |

**لا Python ولا Node** — فقط EXE + مجلدات الحزمة.

---

## 2) التحميل

GitHub Releases → **`Saqr-Windows-Complete-*.zip`**

---

## 3) الهيكل بعد فك الضغط

```
Saqr\
  SAQR_RUN.bat          ← التشغيل الرئيسي (استخدم هذا)
  SAQR_RUN.ps1
  SAQR_DIAGNOSE.bat
  env.template
  .env                  ← تنشئه أنت
  bin\saqr.exe
  web\control_terminal\
  data\
  logs\
```

---

## 4) أول تشغيل

1. **`SAQR_RUN.bat`** (نقر مزدوج)  
2. إن لم يوجد `.env` → يُنشأ من `env.template` ويفتح Notepad  
3. عبّئ على الأقل (للتجربة):
   - `SAQR_MODE=demo`
   - `SAQR_REQUIRE_INTEGRATED_DEMO=false`
   - `SAQR_ENABLE_TRADING=false`
4. احفظ `.env` وشغّل **`SAQR_RUN.bat`** مرة أخرى  
5. المتصفح يفتح اللوحة تلقائياً بعد ~4 ثوانٍ  

---

## 5) أوضاع التشغيل (.env)

| SAQR_MODE | المعنى |
|-----------|--------|
| **demo** | Testnet حي + لوحة؛ **بدون أوامر** (افتراضي) |
| **testnet** | مفاتيح Testnet مطلوبة؛ checklist صارم |
| **live** | Live + `SAQR_ENABLE_LIVE_ACK=true` |

---

## 6) Telegram (اختياري في demo)

- `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` **معاً** أو **فارغان**  
- `/start` للبوت قبل Chat ID  
- للتكامل الإلزامي: `SAQR_REQUIRE_INTEGRATED_DEMO=true`

---

## 7) Binance Testnet

- `BINANCE_TESTNET=true`
- URLs: `testnet.binance.vision` / `wss://testnet.binance.vision`
- مفاتيح API اختيارية في **demo** للأسعار العامة؛ مطلوبة في **testnet**

---

## 8) API للوحة (حقيقية)

- `/api/engine` — حالة WS، السعر، verdict  
- `/api/signals` — إشارات المحرك  
- `/api/positions` — صفقات (إن وُجدت)  

---

## 9) استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| نافذة تغلق فوراً | **`SAQR_DIAGNOSE.bat`** |
| `--check` fails | أصلح `.env` |
| `--version` fails | [VC++ Redist x64](https://aka.ms/v14/vc/redist/x64/) |
| Enter يغلق | طبيعي **بعد** توقف البوت — استخدم **Ctrl+C** للإيقاف |

## 11) من المصدر (مطورين)

```powershell
git clone https://github.com/hassanayar93/Saqr.git
cd Saqr
cargo build --release -p saqr-cli
copy .env.example .env
cargo run --release -p saqr-cli
```
